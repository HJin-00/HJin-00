# 안녕하세요, 백엔드 개발자 김현진입니다 👋

사용자의 문제를 이해하고, 해결 과정을 서비스로 구현하는 개발자입니다.

Java와 Spring Boot 기반 웹 개발에서 시작해,
데이터 분석과 AI Agent 개발로 경험을 넓혀왔습니다.
백엔드부터 AI, 화면까지 연결하며
사용자가 목적을 달성할 수 있는 서비스 흐름을 고민합니다.

### 💡 문제를 정의하는 것부터 시작합니다
어떤 기능을 만들지에 앞서, 사용자가 무엇을 어려워하는지 살펴봅니다.
데이터와 사용자의 상황을 바탕으로 문제를 구체화하고,
기술로 해결할 수 있는 범위를 정리합니다.

### 🔗 서비스 전체의 흐름을 생각합니다
각 기능의 구현과 함께 기능 사이의 연결도 중요하게 생각합니다.
사용자의 입력이 API와 데이터, AI 도구를 거쳐
이해하기 쉬운 결과로 전달되는 과정에 관심이 있습니다.

### 🔍 결과를 확인하고 개선합니다
기능이 동작한 뒤에도 예외 상황과 대화 맥락을 점검합니다.
테스트와 평가를 통해 부족한 부분을 찾고,
수정한 내용이 실제 개선으로 이어지는지 확인합니다.

### 🌱 경험을 연결하며 배웁니다
NHN Academy에서 쌓은 웹 개발 경험을 바탕으로,
LG AX SCHOOL에서 데이터 기반 의사결정과 AI 서비스 개발을 경험했습니다.
새로 배운 기술을 기존 지식과 연결하며 개발의 폭을 넓혀가고 있습니다.
