# 안녕하세요, 백엔드를 공부하고 있는 김현진입니다 👋

Java와 Spring Boot를 중심으로 백엔드를 공부하고 있습니다.
Servlet/JSP와 Spring Boot를 활용한 웹 개발 경험이 있으며,
Python과 FastAPI를 활용한 AI 서비스 구현도 경험했습니다.

NHN Academy에서는 쇼핑몰과 협업 서비스 프로젝트를,
LG AX SCHOOL에서는 데이터 분석과 AI Agent 프로젝트를 진행했습니다.
